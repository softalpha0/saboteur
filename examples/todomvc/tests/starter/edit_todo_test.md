# Edit a todo

## Add a todo
Open the page.
Type "Buy milk" in the "What needs to be done?" box and press Enter.

## Change its title
Double-click the "Buy milk" title, replace the text with "Buy oat milk" and press Enter.
Verify the list has a todo titled "Buy oat milk".
Verify the list has no todo titled "Buy milk".
