# Delete a todo

## Add a todo
Open the page.
Type "Read book" in the "What needs to be done?" box and press Enter.
Verify a todo titled "Read book" is in the list.

## Delete it
Hover over the "Read book" row and click its "×" delete button.
Verify the list no longer has a todo titled "Read book".
